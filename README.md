# ⛪ L'Église De La Rue Des Jardins — Church Website

A responsive bilingual church website built from scratch as a milestone project for the Foundations track of **The Odin Project**.

## 🎯 Project Motivation & Purpose

I noticed that our local church had little to no digital presence, making it difficult for new members and visitors to discover the church, learn about its ministries, and find information about its services.

I chose to build this website as a real-world portfolio project while practicing my HTML, CSS, and JavaScript fundamentals.

The website includes **English and French versions across eight pages**, with language-specific navigation and interactive features.

## 🚀 Live Preview

👉 https://emm0546.github.io/my-first-landing-page/

## 🎨 Features

- **Responsive Layout** — Built with CSS Flexbox and flexible sizing to adapt to different screen sizes.
- **Bilingual Architecture** — English and French versions with language-switching navigation.
- **Interactive Welcome Banner** — JavaScript automatically cycles through welcome messages.
- **Smooth Navigation** — The main call-to-action button smoothly scrolls to the information section.
- **Interactive Registration Form** — Visitors can open the registration form, submit their information, and receive a personalized confirmation message.
- **Interactive Contact Form** — Visitors can submit a message and receive a personalized confirmation message.
- **Church Information Pages** — Includes About, Ministries, and Contact pages.
- **Church Branding** — Custom layout, colors, typography, and Seventh-day Adventist logo integration.

> **Note:** The registration and contact forms currently demonstrate front-end form handling. They do not yet store or send submissions to a backend service.
